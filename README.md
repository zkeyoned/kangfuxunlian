# 康迹 RehabTrack

基于计算机视觉的居家康复训练动作识别与量化评估系统。病人打开手机摄像头做康复动作，系统识别动作、自动计数、算关节角度、当场提示错误、生成训练报告，康复师远程看趋势、调计划。参加 2026 中国国际大学生创新大赛高教主赛道本科生创意组。

具体病种、动作、评价标准尚未由康复师确认，仓库里凡涉及这部分的内容均按「待康复师确认」处理，不代表最终方案。

## 目录归属

| 目录 | 内容 | 负责人 | 交付物 |
|---|---|---|---|
| `materials/` | 计划书与比赛材料 | 材料（胡） | 项目计划书、路演 PPT |
| `frontend/` | 前端页面 | 前端（景） | 可操作的前端演示页面 |
| `database/` | 数据库 | 数据库（得） | 数据库、数据字段说明、测试数据 |
| `backend/` 与 `algorithm/` | 后端与视觉算法 | 后端与视觉算法（常） | 视觉分析模块、后端接口、完整联调演示 |
| `medical/` | 康复需求与医学沟通 | 医学（陈） | 需求确认表、动作与指标说明、康复师反馈 |
| `deploy/` | 部署与上线 | 数据库（得）暂管 | 服务器、HTTPS、进程守护 |

`docs/` 是公共目录，其中 `docs/03-接口契约.md` 由前端、后端、数据库三方共有，改动必须三方知会并在 `docs/decisions/` 记一条决定记录。

## 怎么跑

```bash
pip3 install -r requirements.txt
./start.sh          # 前台常驻，Ctrl-C 停止
```

另开一个终端窗口测试接口：

```bash
python3 tests/test_api.py
```

启动后默认端口 8801：

- 前端演示页面（如果 `frontend/` 下已经有页面文件）：http://127.0.0.1:8801/
- API 文档：http://127.0.0.1:8801/docs
