# v0.2 模型接入和复跑报告

输入：用户提供的77秒 annotated.mp4（1720帧，640×480）。**这不是原始视频，含旧版文字和骨架叠加，会干扰检测。因此仅用于集成与故障诊断，不能得出临床准确率或严格模型排名。**

| 方案 | 总帧数 | 分数/入镜检查通过 | 全部质量检查通过 | 算法完整计数 | 平均推理耗时ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| mediapipe / detected | 1720 | 15 | 0 | 0 | 15.6 |
| rtmpose / detected | 1720 | 101 | 0 | 0 | 26.4 |
| rtmpose / full-frame | 1720 | 1050 | 672 | 1 | 16.7 |

“通过”只是配置规则通过，不代表人工确认正确。各模型分数尺度不同，阈值分别为MediaPipe 0.6、RTMPose 0.3；该数值不是可直接比较的准确性指标。平均耗时只包含逐帧模型推理，不含加载、视频编码、显示，不等于端到端FPS。

## 观察

- YOLOX-tiny+RTMPose检测模式在截断近景上多次找不到人；没有静默回退或伪称检测成功。
- 显式选择固定单人整图ROI后可以获得更多连续姿态；它没有人数检测，需要用户保证只有一人。
- 固定单人模式约61.25–66.75秒识别到1次完整动作（按输入视频时间），尚未有人工计数标注，不能声称计数准确。
- 出画脚踝、持续错误点、双腿重叠仍不能保证解决。质量门控会导致暂停和漏计。
- 复跑时MediaPipe与原始摄像头记录的通过帧数不同，不应直接比较：输入已烧录标注、重新编码，跟踪状态也重建。

## 测试

- 21项逻辑/适配测试：保留原10项，新增COCO映射、坐标滤波、异常跳变、疑似串腿、遮挡重捕获、肩部缺失、两种ROI行为等。
- 两种真实模型及ONNX在本机成功加载、推理。固定单人RTMPose空白图输出经质量检查被拒绝。
- 三次完整视频分析均正常退出并生成摘要、逐帧数据、可播放视频。
- 不自动打开用户摄像头；现场试拍需要用户点击允许按钮。
