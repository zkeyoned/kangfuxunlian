# 验证报告

## 已完成的软件检查

- Python 3.12.10 / Windows x64。
- 10项自动测试：90/180度与退化几何、非正方形像素坐标修正、完整往返、双次计数、防静止重复计数、幅度不足但完成往返、遮挡中断与恢复、中途开始/未完成、采样缺口与非法时间、不同采样率计时、配置校验。
- 实际下载并加载 MediaPipe Pose Landmarker Full 模型；推理20帧空白视频，可靠帧0、计数0，符合预期。
- 标注视频可解码20帧，末帧时间0.95秒，与输入一致。
- 这些是软件逻辑与模型加载测试，不是模型人体识别精度验证。

- 中文启动窗口实例化检查通过：启动时不访问摄像头，视频保存默认关闭。
- 项目自身虚拟环境的真实模型推理通过，pip check无依赖冲突。
- 本机窗口运行时：Python 3.14/Tk 8.6；算法运行时：Python 3.12.10。

## 后续验证表建议

为每段经授权的测试视频记录：匿名人物编号、机位、分辨率、动作侧、人工次数、人工动作起止、遮挡片段、算法次数、漏报/误报、时间误差。用独立参考测量验证角度；按人物划分开发与测试数据，避免同一人的相似视频同时用于调参与最终评估。保持原始标注，不为匹配算法而改变人工答案。
