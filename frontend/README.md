# frontend（前端负责人：前端（景））

## 这个目录里是什么

前端页面源码（当前为康师复网站 v4，纯静态：`index.html` / `app.js` / `styles.css` / `assets/`）。数据一律走 `docs/03-接口契约.md` B 节的接口，不直接读数据库。

后端服务启动时会把本目录作为静态站托管：`./start.sh` 后打开 http://127.0.0.1:8801 即页面；本目录单独查看见下文。

## 接口字段从哪查

所有接口路径、请求体、返回体字段以 `docs/03-接口契约.md` B 节为准，浏览器打开跑起来的服务的 `/docs` 也能看到交互式文档。字段如果需要调整，先改 `docs/03-接口契约.md` 并知会后端（常）和数据库（得），再改代码。

## 建议页面清单

以下是建议的页面划分，具体交互和视觉由前端负责人决定，接口对应关系仅供参考：

| 页面 | 说明 | 主要接口（docs/03 B 节） |
|---|---|---|
| 登录 | 手机号/用户名 + 密码登录，患者和康复师共用一套入口，按角色跳转 | 登录接口 |
| 今日计划 | 患者查看当天要做的训练项，展示每项的目标次数、组数、规则参数 | 今日计划查询接口 |
| 训练 | 打开摄像头做动作，实时显示计数和提示，一组做完调用算法模块拿结果并上报 | 训练开始、每组结果上报、训练结束接口 |
| 报告 | 患者查看历史训练趋势、疼痛评分记录 | 训练历史/报告查询接口 |
| 康复师工作台 | 康复师查看本机构患者列表、训练趋势、异常提醒，调整训练计划 | 患者列表、患者详情、计划编辑接口 |
| 规则库 | 康复师或管理员查看和管理各动作的规则参数版本、激活状态 | 规则版本查询、激活接口 |

具体病种、动作候选方案待康复师确认，页面里的动作名称和评价维度暂按 `docs/03-接口契约.md` 里的示例走，后续可能调整。

## 康师复网站 v4（2026-09-19 前端负责人交付）

纯静态页面，无构建步骤：`index.html` + `app.js` + `styles.css` + `assets/`。

本地查看：

```bash
cd frontend && python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080 。当前版本未接后端接口与摄像头（数据存 localStorage），接入以 `docs/03-接口契约.md` B 节为准。
