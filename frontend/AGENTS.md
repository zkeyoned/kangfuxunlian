# frontend/ 规则（负责人：前端（景））

## 归属

本目录归前端（景）负责。

## 交付物清单

- 可操作的前端演示页面（不进本仓库，见下）

## 可以做什么

- 页面从零做，技术栈自选。
- 参考本地已有的一套可运行参考页面（不在本仓库里，需要时找数据库（得）要）。
- 在 README.md 里补充自己的开发说明、启动方式（页面代码本身放在自己的项目里，不提交进本仓库）。

## 不可以做什么

- 前端页面代码不进本仓库。frontend/ 目录只保留 AGENTS.md 和 README.md。
- 数据一律走后端接口，不允许直接读数据库文件或写死假数据当正式功能。
- 字段以 docs/03-接口契约.md B 节为准，不得自行发明字段名；需要新字段先找后端（常）、数据库（得）沟通，改 docs/03，在 docs/decisions/ 记一条。
- 摄像头相关页面必须走 HTTPS，不允许在非安全上下文里请求摄像头权限。

## 开工前读什么

1. PROGRESS.md
2. frontend/README.md
3. docs/03-接口契约.md B 节

## 完工标准

- 页面所有数据请求都能对上 docs/03-接口契约.md B 节的接口与字段。
- 涉及摄像头的页面在 HTTPS 环境下可用。
- 更新 PROGRESS.md 里前端这一行的状态与日期。
