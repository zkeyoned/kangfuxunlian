# 动作2网页候选规则 v0.1
依据用户提供的《康迹_动作2_仰卧直腿抬高量化标准_v0.1.docx》。工程参数待康复师确认与真人验证。
动作2独立按抬腿角计次，膝控制单独评价。网页先在同一侧面画面选取床面两点（朝脚方向）；不以坐姿角度或90度偏置信号作为真实角度。
默认30度、进入±5度/膝屈曲≤10度，保持±8度/≤15度，5秒；启动8度0.2秒，回落5度0.2秒，闭合±5度0.5秒，幅度至少15度。持续屈膝15度0.3秒锁定本次不达标。丢帧不补时，持续2秒中断；30秒未闭合重新准备。完整次数与目标完成次数分开。
增加 /api/live/{session}/surface 标定端点，坐标归一化0..1，两点须从头端到脚端。每次训练需重新标定。
独立视觉报告增加 raise_peak_deg、raise_excursion_deg、knee_flexion_max_deg、knee_bend_delta_deg、knee_control_met、bend_event_count、joint_target_reached、raise_to_first_peak_s、time_to_target_s、target_completed、reference_frame 与规则版本；不可算存null。沿用独立 training_reports，不映射旧rep解剖角字段。
新的动作2方案条目注明 rule_version=slr_v0.1_surface。旧条目不静默改变角度含义，患者需康复师重新发布；自主模式明确采用新演示规则。其他动作不变。
录像沿用用户已要求的保存流程，本次不改变。肌肉发力、骨盆旋转与腰椎贴床不自动判断。前端在外部目录，需单独分发。
