# 坐站候选量化规则
来源为用户提供的动作3坐站v0.1文档；内部代号保持8/stand，不更改扶椅微蹲。
新增双基线标定与人工站姿确认、辅助方式和座椅配置。膝角、髋相对高度、站姿躯干共同确认站起。坐姿伸膝0次，半起身未完成，站起但未坐回0完整次数。保持默认1秒。正常前倾不扣分。
新方案版本 sts_v0.1_dual_baseline；旧坐站方案需重新发布。独立视觉接口 /api/live/{id}/sts-calibration 接收 stage=sit|stand|confirm，配置座高、坐垫、脚位、辅助方式；只计标定后正式动作。
报告新增 attempts、standing_reached、cycle_completed、goal_met、evaluation_status、rise_to_stand_s、sit_down_s、stand_knee_deg、hip_rise_peak、trunk_forward_peak_deg、stand_sway_range、seat_contact_verified=unknown；不可算存null。保存实际配置和双基线，不代表临床测试或康复疗效。既有真实录像授权流程保持不变。
