# 扶椅微蹲候选标准 v0.1

依据用户提供的《康迹_动作4_扶椅微蹲量化标准_v0.1》。待康复师确认，训练辅助，非医疗诊断。

- 编号保留 squat/6，exercise_id=supported_mini_squat；rule_version=squat_v0.1_joint。
- 膝屈曲为180减二维膝夹角。默认30度，进入±5度、维持±8度，保持1秒，0秒明确记录 no_pause。初始演示1组3次，已有用户组次不覆盖。
- 人工确认双手稳定支撑，舒适站姿2秒标定。初始屈曲不超过10度且距离目标至少20度。髋下降D按初始小腿长度归一化，不是厘米、负重或重心。
- 屈曲增加8度且D≥0.02持续0.2秒启动；目标范围且D≥0.03持续0.2秒进入保持。返回初始姿态0.5秒后计完整次数，需屈曲变化≥15度、D峰值≥0.03、关键阶段可靠。
- 超过目标+8度持续0.3秒锁存 depth_exceeded，range_control_met=false。本次后续回到目标不能消除此事件。正常躯干前倾不套用旧15度提示。
- 遮挡立即中断连续保持；当前实现保守地将有丢点的整次尝试标为无法评价。持续2秒或身份改变重新标定。30秒未闭合记未完成并重新准备。
- 报告记录 attempts、完整次数、goal_reps、unable_to_evaluate、目标完成率（无可评价完整次数为null）。逐次含 knee_flexion_peak_deg、knee_flexion_excursion_deg、hip_drop_peak、trunk_forward_peak_deg、trunk_hold_range_deg、descent_to_first_peak_s、time_to_target_s、target_hold_s、rise_s、range_control_met、goal_met、baseline、setup 和 rule_version。
- 躯干保持波动采用最长有效保持段P95减P5，少于1秒为空。膝角速度正值为伸膝，flexion_velocity_deg_s相反。支撑力、左右受力、脚跟接触、内扣无法由当前侧面模型验证，不输出合规结论。
- 本地视觉服务新增 POST /api/live/{id}/squat-setup，参数 support=chair|fixed_surface、support_confirmed=true、foot_position。启动需新版本标记，旧方案需重新发布。
- 真实数据沿现有报告JSON保存，不更改原数据库表。外置网页与视觉桥接不在本仓库，联调说明单列；队友仅拉本PR不能获得完整网页服务。

审核：前端景、数据库得。参数口径待康复师确认，合成状态机测试不代表实拍准确率。
