# 0003 · 双向康复关联

- 日期：2026-09-20
- 状态：本地实现，待前端、数据库审核。
- 背景：真实注册后的独立患者没有查找和关联康复师的入口。
- 决定：按注册账号精确查找，双向申请，接收方明确接受后建立主责康复师关系。每个患者最多一位，康复师可有多位患者。复用 patients.therapist_id，不迁移患者机构。
- 权限变化：普通康复师从原机构全体患者范围收紧为本人已关联患者，所有集合与详情接口保持一致。机构管理员的机构边界不变。
- 增量存储：backend/migrations/001_care_requests.sql 创建申请表和待处理申请唯一索引，不直接编辑数据库负责人管理的原始 schema 和 seed；待审核统一归档。
- 联系方式：邮箱注册无手机号，不猜测、不补造，直接分享注册邮箱查找。补绑验证后续设计。
- 影响：两端增加关联入口。接受/拒绝/撤回/解除均真实入库，解除暂停计划并撤销原康复师的关联权限，历史不删除。视觉简报入库与站内消息传递仍为独立待办。
- 审核：后端提出，前端、数据库待审核，未声称已确认。
