# 0002 · 患者真实注册

- 日期：2026-09-19
- 状态：本地实现，待前端与数据库负责人审核，尚未合并。
- 背景：外部前端的注册仅保存浏览器缓存，数据库登录接口无法识别这些账号。
- 决定：增加患者注册接口，复用现有 users、patients、institutions 和 audit_logs 表及密码哈希方法。各自注册账号使用独立隔离空间，康复师自行注册暂不开放，避免获得现有患者及公共规则管理权限。
- 边界：不自动迁移浏览器缓存密码；患者重新注册。无短信或邮件验证，无自动关联康复师，无默认临床计划。现有账号和训练记录保留。
- 影响：外部前端应改用注册 API，正确读取 error/detail，注册后走正常登录。数据库无需改表。机构绑定流程另行讨论。
- 审核：后端提出；前端、数据库待审核，未声称已知会。
