# 04 · 部署方案（通用做法）

## 一句话

**一台最便宜的轻量云服务器 + 一个域名 + 免费证书**，就够试点期用。服务器不跑 AI 模型（模型在手机浏览器里跑），所以不需要 GPU、不需要大内存。当前由数据库负责人（得）暂管部署，后续视人手调整。

## 需要什么

| 项 | 规格 | 为什么 | 量级 |
|---|---|---|---|
| **云服务器** | 2 核 2G、40G 系统盘、Linux 主流发行版 | 只跑 FastAPI + SQLite + 反向代理，实测空闲内存占用 < 200MB | 各云厂商轻量应用服务器最低档，每月几十元，学生认证通常有优惠（以官网现价为准） |
| **域名** | 任意，如 `<你的域名>` | 浏览器**只在 HTTPS 下允许打开摄像头**，HTTPS 需要域名 | 一年几十元 |
| **证书** | Let's Encrypt | 反向代理自动申请续期，零操作 | 免费 |
| 对象存储（可选） | 最小档 | 每日数据库备份 | 几乎免费 |

**不需要**：GPU、Docker、Kubernetes、Redis、消息队列、负载均衡。谁提这些，先问并发量有多大。

## 一个必须提前知道的坑：备案

**大陆地区的服务器 + 域名对外提供网站服务，通常需要 ICP 备案**，周期约 1-3 周，且要以个人或单位名义提交。三条路：

| 路 | 优点 | 缺点 | 建议 |
|---|---|---|---|
| A. 大陆服务器 + 备案 | 访问最快最稳 | 等 1-3 周；学生个人备案可行但流程繁 | 正式试点走这条，尽早启动 |
| B. 境外节点服务器 | 不用备案，当天能上 | 校园网访问略慢；部分线路偶发不稳 | 演示和联调期走这条 |
| C. 学校内网服务器 / 实验室机器 | 免费、快 | 校外访问不了，手机要连校园 Wi-Fi | 联调可以，正式演示别赌 |

推荐：**先境外后大陆**，先租一台境外轻量服务器把链路跑通，同时开始办大陆备案，备案下来后把数据迁过去（拷贝一个 sqlite 文件即可）。

## 上线步骤（Linux，约 5 分钟）

```bash
# 1. 域名 A 记录指向服务器公网 IP；安全组放行 80、443
# 2. 把代码拷上去（scp / git clone）
scp -r kangfuxunlian <用户名>@<服务器IP>:~/
# 3. 一键装（示例为 Ubuntu 系脚本，阿里云 Linux 用对应脚本）
ssh <用户名>@<服务器IP>
sudo bash ~/kangfuxunlian/deploy/install.sh <你的域名>
# 4. 改演示密码（种子数据里的密码只能本机用）
```

`deploy/install.sh` 做的事：装 Python venv 与依赖 → 装反向代理软件 → 建独立系统用户 → 写服务守护单元（崩了自动拉起）→ 写反向代理配置（自动 HTTPS）→ 启动。`deploy/install-alinux.sh` 是同类脚本在阿里云 Linux 发行版上的适配版本。

## 上线后日常

| 事 | 命令 |
|---|---|
| 看服务活没活 | `systemctl status rehabtrack` · `curl https://<你的域名>/healthz` |
| 看日志 | `journalctl -u rehabtrack -f` · `tail -f /var/lib/rehabtrack/logs/app.log` |
| 更新代码 | `git pull && systemctl restart rehabtrack` |
| 备份 | `sqlite3 /var/lib/rehabtrack/rehabtrack.sqlite3 ".backup /backup/$(date +%F).sqlite3"`（放定时任务每天一次） |
| 换 PostgreSQL | 数据量增长到几十万条 session_items 再说 |

## 本机 / 局域网演示（不买服务器也能演）

```bash
./start.sh            # http://127.0.0.1:8801
```

- 电脑本机打开：`localhost` 例外，**不用 HTTPS 也能开摄像头**。
- 手机连同一 Wi-Fi 访问电脑 IP：**http 下手机打不开摄像头**（浏览器限制），两个办法：
  1. 手机用「演示模式」（合成信号，链路完整，只是没画面）。
  2. 用本地自签证书方案（`deploy/Caddyfile` 的本地变体），手机需要点一次"信任"，比赛演示前准备好。
- 答辩现场最稳的组合：**电脑本机摄像头做患者端 + 手机开康复师工作台看数据实时进来**。
