# 00 · 项目说明

## 一句话定位

患者仅需打开摄像头，即可获得动作识别、自动计数、关节角度、质量提示与训练报告；康复师可远程查看趋势并调整计划。

## 痛点

家庭训练缺的不是视频教程，而是持续的监督、反馈与证据。

- 患者：不知道动作是否标准，次数靠自记，缺少即时鼓励，担忧隐私。
- 康复师：院外过程不可见，复诊信息碎片化，随访耗时。
- 机构：服务在出院后中断，人力难以覆盖高频随访。
- 家属：难判断训练是否安全有效，陪练时间有限。

## 产品闭环五步

1. 计划：康复师或用户选择动作、组数、目标角度。
2. 准备：拍摄角度引导、环境检查、身体关键点完整性检查。
3. 训练：骨架叠加、自动计数、角度显示、低干扰语音/文字反馈。
4. 评估：完成率、合格率、最大角度、速度与稳定性摘要。
5. 随访：趋势图、异常记录、计划调整与复诊沟通。

## MVP 边界

- 单人、固定机位、光线基本稳定、指定拍摄侧面或正面。
- 暂不支持复杂遮挡、多人、急性疼痛判断和诊断性结论。
- 候选动作：膝关节术后四类高频动作，直腿抬高、屈膝训练、深蹲、坐站训练。**具体病种、最终动作与评价标准尚未由康复师确认，以上为候选方案**，以 `medical/需求确认表.md` 的康复师签字结果为准。

## 创新点

| 创新点 | 落地价值 |
|---|---|
| 可解释动作状态机 | 把动作拆成开始、峰值、稳定、返回阶段，计数与扣分依据可追溯。 |
| 个体化目标 | 用术后阶段、健侧基线和康复师目标配置阈值，减少一把尺子量所有人。 |
| 隐私友好设计 | 优先端侧提取关键点，默认不保存原始视频，只保留必要的结构化训练指标。 |
| 双端闭环 | 患者即时反馈与康复师周期管理共享同一套指标，缩短复诊沟通链路。 |
| 低门槛部署 | 利用现有手机或电脑摄像头，不要求额外穿戴硬件，适合轻量试点。 |

## 隐私红线

- 数据最小化：默认仅处理关键点和训练指标，原始视频默认不保存，采集目的明确。
- 知情同意：说明用途、保存期限、访问对象、退出方式，研究与产品服务分别授权。
- 权限隔离：患者、康复师、管理员分级，机构间逻辑隔离，敏感操作留审计日志。
- 安全措施：传输加密、凭证安全存储、最小权限、备份恢复、漏洞与事件响应。
- 用户权利：支持访问、更正、导出与删除，撤回授权不影响此前合法处理。
- 不采集与目标无关的数据，不将试验数据用于未授权训练，不对低置信度结果做强提示，不向患者承诺治疗效果。

## 参赛表达边界

现阶段定位：创新验证项目，而非医疗诊断产品。所有建议均用于训练辅助，不替代医生诊断、复查或个体化处方。

避免宣称"替代康复师"或"达到医疗诊断级"。更可信的表述是：为规范训练与随访提供可解释、可量化的辅助工具。

疼痛、跌倒风险或异常情况，产品应提示停止训练并联系专业人员，不做临床结论。
