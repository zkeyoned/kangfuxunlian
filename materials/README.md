# 计划书与比赛材料

本目录由计划书与比赛材料负责人（胡）负责，交付物是项目计划书和路演 PPT。

## 放什么

- 项目计划书（商业计划书 / 申报书），Word 或 PDF。
- 路演 PPT。
- 演示用的视频脚本、分镜稿。
- 比赛要求的其他申报材料。

## 版本命名规则

文件名统一带日期或版本号，方便区分历史版本，旧版本不要删除，留档对比：

```
商业计划书-v1.0.pdf
商业计划书-v1.1-20260920.pdf
路演PPT-v1.0.pptx
路演PPT-20261005-复赛版.pptx
```

## 内容口径

写文档时注意：

- 具体病种、康复动作、评价标准尚未由康复师确认，一律写「待康复师确认」，不要写成已定方案。
- 不写任何真实姓名、不写域名和服务器信息、不写项目的演变过程，只写项目本身的作用和目标，详见仓库根目录 `CONTRIBUTING.md` 和 `docs/00-项目说明.md`。
